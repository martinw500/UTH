Open this page over HTTP

This tool loads ES modules, which browsers block when a page is opened straight from disk over file://. Nothing below would run.

From the project folder, run npm run dev and open http://localhost:5500/text-from-image/.

Text from Image

Copy the text out of a screenshot, a photo of a page or a scanned PDF

Everything runs in your browser. Your images are never uploaded. The first time, it downloads the reading engine and the language you pick (a few MB each), then keeps them.
Drop images or a PDF here or
Or paste a screenshot with Ctrl+V. JPEG, PNG, WebP, HEIC and scanned PDFs.
Check names and numbers: recognition is good, not perfect. You can edit the text here before copying it.
