YouTube Downloader

Save a video, or just its audio as an MP3

This tool is for personal use only. Please respect YouTube's Terms of Service and copyright laws.

Still not working? Two ways that always work

1. Run one command on your own computer

Your home internet is not blocked the way a shared cloud server is, so this works even when the button above does not. You need Python installed, then paste these into Terminal (Mac) or Command Prompt (Windows):

pip install yt-dlp

The file lands in whichever folder the terminal is sitting in — usually your home folder.

2. Run this whole site on your computer

Then every quality works, videos of any length work, and the MP3 button stops being limited by file size. In the project folder, run these in two terminals:

npm run dev
npm run dev:api

Then open http://localhost:5500/youtube-downloader/. Full instructions are in docs/SETUP.md.
